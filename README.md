# Agent Skills

Central repository for reusable Agent Skills.

This repository is the canonical source for skills. Agent-specific directories should
contain symlinks to these skill folders, not independent copies.
The default sync targets cover Claude Code plus the shared `.agents/skills`
compatibility path used by Codex, Pi, OpenCode, GitHub Copilot, Windsurf, and
Gemini CLI.

## Structure

```text
.
|-- skills/
|   |-- _template/
|   |   |-- SKILL.md
|   |   |-- assets/
|   |   |-- references/
|   |   `-- scripts/
|   `-- <skill-name>/
|       `-- SKILL.md
|-- docs/
|   |-- agent-discovery.md
|   |-- authoring-portable-skills.md
|   `-- repository-structure.md
`-- tools/
    |-- README.md
    |-- check
    |-- lib/
    |   `-- skills.sh
    |-- sync-agent-skills
    `-- unsync-agent-skills
```

## Quick Start

Create a skill from the template:

```sh
cp -R skills/_template skills/my-skill
```

Edit `skills/my-skill/SKILL.md`, then choose skills interactively to link them
into the local agent-specific skill directories:

```sh
tools/sync-agent-skills
```

Select a subset explicitly for scripts:

```sh
tools/sync-agent-skills code-review diagnose
```

Use `--all` for unattended bulk sync:

```sh
tools/sync-agent-skills --all
```

Remove only selected links that point back to this repository:

```sh
tools/unsync-agent-skills
```

After moving this checkout, remove stale links from its old location with:

```sh
tools/unsync-agent-skills --all --prune-dangling
```

With no skill names or `--all`, non-terminal invocations fail instead of
silently syncing every skill.

## Development

Lint the bash tools and any scripts shipped with skills:

```sh
tools/check
```

Requires [`shellcheck`](https://www.shellcheck.net/) (`brew install shellcheck`
on macOS).

## Conventions

- Each skill lives in its own directory under `skills/`.
- Each skill starts with a `SKILL.md`.
- `SKILL.md` files include YAML frontmatter with `name` and `description`.
- Skill directory names match the `name` field for maximum compatibility.
- Reusable helper scripts live in the skill's `scripts/` directory.
- Static files, examples, and templates live in the skill's `assets/` directory.
- Longer background material lives in the skill's `references/` directory.
- Repo-wide helper tools live under `tools/`.
- Agent-specific install directories are generated by `tools/sync-agent-skills`.
